# 大纲记忆

用于记录可复用的大纲经验，服务于创作前检索、创作后纠错与长期迭代。分类本身不是记忆条目；只在对应分类下记录有明确依据的经验。

新增条目统一使用以下格式，编号在后续修改中保持不变：

```text
### OUT-0001｜简短、可检索的经验标题
阶段：大纲
状态：候选
内容：一条可直接指导选题展开和结构设计的具体经验。
```
