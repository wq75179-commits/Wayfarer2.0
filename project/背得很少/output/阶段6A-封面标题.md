# 阶段6A：封面标题设计

> 包装阶段记忆查询（2026-10-09）：0 条，本阶段不引用跨期包装经验。
> 参考事实（来自各期 README 数据记录）：频道 80%+ 流量来自推荐；白纸记忆法（标题“为什么有些人能轻松记住一切？…”）CTR 6.8%；10倍速学习因标题与正文错位导致 CTR 下滑。

## 一、承诺兑现度检查

- 一句话承诺：画线、截图、收藏只会让你觉得学会了；学霸课本干净，是因为他们把力气花在合上书之后
- 承诺类型：认知颠覆型（允许“为什么”句式作钩子）
- 标题方向：《為什麼學霸很少畫重點？》/《你畫的重點，正在騙你》/ 画线+截图+收藏版本；禁用“別再畫重點”
- 文稿兑现：
  - 打破（一至三）约 45%：眼熟≠想得起、画多没重点、截图同理 ✓
  - 植入（四）约 12%：学霸画线是为了出题 ✓
  - 重建与行动（五至七 + 结尾）约 43%：先问再读、合意困难、四件事 ✓
  - 叙事顺序：先打破再重建 ✓
- 结论：可以进入标题设计

## 二、三组方案

### 方案1：打破旧认知

- 视频标题：**你畫的重點，正在騙你｜為什麼畫得越多，越記不住？**
- 封面文字：
  - 上：畫滿重點
  - 下：等於沒畫
- 侧重：打破旧认知｜情绪：危机感｜风格：直接判断
- 封面与标题：补充信息（标题说“骗你”，封面给出结论）
- 标题党等级：黄灯偏绿。“正在骗你”情绪强，但对应文稿“熟悉错觉”“自我欺骗的安心感”；“越记不住”对应“画线练的是认得，考试考的是想得起”
- 预期反应：看到自己的课本或笔记被点名，产生“我是不是做错了”的不安

### 方案2：悬念提问（推荐）

- 视频标题：**為什麼學霸很少畫重點？他們畫完，會多做一個動作**
- 封面文字：
  - 上：學霸只畫一處
  - 下：然後多做這一步
- 侧重：底层原理 + 悬念｜情绪：好奇心｜风格：悬念提问
- 封面与标题：制造悬念（标题和封面都指向“那个动作”，答案在植入段揭晓）
- 标题党等级：绿灯。“很少画”“多做一个动作”都是文稿原话，答案在第四段完整兑现
- 预期反应：“学霸到底多做了什么？”这个问题只有看视频才能回答
- 推荐理由：
  1. 开场删掉“多做一个动作，我放在中间揭晓”之后，悬念交给标题来承担，不用在口播里说元叙述
  2. 观众点进来就带着问题，植入段正好揭晓答案，能托住广告段的留存
  3. “为什么学霸…”是推荐流里最容易让人自我对照的问法

### 方案3：扩展到截图收藏（破圈）

- 视频标题：**畫重點、截圖、收藏，為什麼你學了還是不會？**
- 封面文字：
  - 上：截圖≠學會
  - 下：48小時規則
- 侧重：新方法 + 成年人场景｜情绪：获得感｜风格：问题 + 解法
- 封面与标题：强化对比（标题点出问题，封面给出解法线索）
- 标题党等级：绿灯。截图、收藏在第三段，48 小时规则在第七段，都有完整内容
- 预期反应：35–54 岁、不再画线但天天截图的观众会觉得在说自己
- 风险：“48小时规则”只占文稿约 3%，封面不宜比它在正文里的分量更重；如选此方案，可改封面下行为“都是假學習”

## 三、可选变体

- 借用白纸记忆法的验证钩子：**為什麼有些人能輕鬆記住一切？學霸很少畫重點的原因**
  - 优点：文稿开场就是这句，标题与开场无缝衔接
  - 缺点：和频道最高表现那期标题高度相似，老观众可能以为是旧片

## 四、自检

- 契约遵守：三组都是认知颠覆型。方案2用“为什么”作钩子，主体仍是先打破再重建；方案3带解法，但标题主体是问题，没有变成快速工具型
- 差异化：方案1 打击旧认知（危机感），方案2 悬念（好奇心），方案3 场景扩展（获得感），信息侧重、情绪、风格三项都不同
- 标题党：方案1 黄灯偏绿，方案2、3 绿灯；均不使用“別再畫重點”这类与“少画、画对”立场冲突的绝对化说法
- 承诺兑现：三个标题承诺的内容（画线骗人 / 学霸多做的动作 / 截图收藏）在文稿中都占 10% 以上，合计覆盖主体内容

## 五、商单相关

- 标题与封面不放书名：本期是学习方法视频，书名进标题会被当成广告片，影响推荐点击
- 书名、出版社、购书链接放在简介和置顶留言（6B 处理）
- YouTube 后台勾选“包含付費宣傳”

## 六、用户定稿（2026-10-09）

- 封面（用户自制）：為什麼學霸 / 很少畫重點 / 卻能輕鬆記住？（需把“么”改“麼”、“松”改“鬆”）
- 视频标题：**畫得越多越記不住？一個動作讓你成為高效學習者｜高效學習#23**
- 封面与标题关系：封面问“为什么学霸画得少却记得住”，标题从观众自己一侧问“为什么画得多却记不住”，并给出“一个动作”的悬念，不复读
- 标题党等级：前半句绿灯；“成為高效學習者”偏大，黄灯，由第四至七段的“改成题目、先问再读”兑现
