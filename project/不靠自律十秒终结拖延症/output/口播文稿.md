**不靠自律
十秒终结拖延症
打开1个行动开关，10秒擊潰拖延症，立马变身行动派｜一本書終結你的拖延症

很多人都觉得自己有拖延症。有很多事情都想做，但就是拖着没办法立刻行动。可能是买了三个月的书还没看一页，说了半年的健身计划一直搁置。还经常责怪自己：我就是太懒，不自律，没有意志力。

日本作家大平信孝在《一本书终结你的拖延症》开宗明义地说：
拖延和自律没有关系，也不是你的问题，而是人人都有拖延症。真正决定我们能不能行动的，是大脑深处的伏隔核，而激活它的方法简单到只需要十秒。
诺奖得主 Daniel Kahneman 研究发现，我们的大脑有一个叫做损失规避的机制。简单说，就是大脑对痛苦的感知，是对快乐感知的两倍。
当你面对一项任务，天生节能的大脑就开始算账：现在开始做，会让我损失两倍的能量。而对于完成后的成就感却缩水计算。就像一个偏心的会计，专门把支出往大了算，把收入往小了记。
大脑里这个痛苦放大器，让你能不做就不做，拖一天是一天，每个人都是这样。行动派不是天生自律，他们只是找到了绕过这个放大器的方法。
那到底怎么绕过去呢？
答案就藏在花生米大小的伏隔核里。它专门负责评估这件事值不值得你付出努力。你可以把它理解成我们的行动开关。

牛津大学 Mark Walton 团队的实验发现，在小白鼠看到奖励信号却保持不动的时候，伏隔核里的多巴胺几乎没有变化。但当它迈出第一步，多巴胺就大幅涌现。
我们常以为有了动力才去行动。真相却是——先行动了，才会有动力。
这在临床上也得到了验证，心理学家 Neil Jacobson 发现，长期拖延的人，伏隔核处于休眠状态。但只要做一个极其微小的动作，哪怕只是站起来走两步，就从外部唤醒了伏隔核。多巴胺开始分泌，行动力快速恢复。
这就是心理学上说的由外而内，不是等感觉准备好再行动，而是用行动带出感觉。
并且这个过程会自我加速，你做了一个微小动作，伏隔核被激活，释放多巴胺。而多巴胺让大脑对原本觉得很难的事，突然感觉没那么难了。于是你继续做下去，更多的多巴胺涌出来，越干越有劲。
所以关键根本不是逼自己坚持。而是想办法用最小的动作，先把伏隔核叫醒。
接下来分享5个今天就能用的科学方法。

第一个：十秒法则。
就是先试着做十秒钟。比如打开文档敲下标题和日期。打开衣柜扔掉一件旧衣服。这有两个好处：一是你知道十秒钟就能做完，就不会抗拒，降低了行动门槛。二是你既然缩短到这么简单，失败的几率低，心理压力也就小，自然容易去完成。很多时候，当你开始做了一点点后，心理会觉得，原来没想的那么难啊！神奇的是，在你扔掉第一件杂物的时候，你会自然地就顺手扔掉第二样、第三样……短短10秒的初始行动，完全触发伏隔核。多巴胺给你带来更大的干劲儿接着做，不知不觉就打扫完了整个房间。

第二个：前一天先做一点。
对于麻烦繁琐的事，不拖延的关键不是在当下的这一秒，而是在前一天先碰它一下。比如你不想拖延明天的报告，就在今天下班前先敲出标题和第一行。对于你明天要做的题，今天晚上就先写一道。明天要去运动？今晚把运动服放在床头。为什么这招好用？因为未完成的事情会挂在脑子里，就像手机后台没关掉的程序。当你第二天早上看到那个已经打开的文档、摆好的运动服，大脑会自动想接着做。

第三个：习惯叠加。
就是把新行为绑在旧习惯后面。
比如，刷完牙喝一杯水。上了车戴上耳机听播客。我的习惯是，散步慢跑时听电子书；在家看电视时，边看边做伸展运动。
当你把新习惯叠加在每天固定的行为上面，久而久之，大脑就会形成条件反射，你就不再需要耗费额外的动力去坚持了。

第四个：在相同的地方，做相同的事情。
这在心理学上叫做锚定效应。比如那张沙发你只是用来看电视的，这张桌子只是用来读书的，那你每次坐上沙发就会特别容易放松，去到那张桌子，记忆东西就特别得心应手。除了地点，时间也可以定锚，比如每天下午三点喝杯茶，然后回复电邮。重复做，效益就会变大，拖延症也会明显减轻，让你顺畅地完成日常工作和学习。
如果家里空间有限，也可以用一些小仪式。比如学习时戴上那副降噪耳机，或者把台灯调到某个亮度。让大脑知道：这个信号出现了，该干活了。

第五个：提不起劲时，先活动一下身体。
如果你下次觉得不在状态、不想干活的时候，试着先让身体动起来。
因为身体和思想是挂钩的，情绪会受肢体动作的影响。觉得很累时，不用勉强拿出干劲，只要稍微活动一下身体，比如简单地转转肩膀、伸个懒腰；原地弹跳、拍打自己的大腿，抖擞一下精神。或者下楼买杯咖啡，就能大幅提升行动力。因为这些微小的身体活动，都能促使大脑释放多巴胺。

最后，给大家提个醒：不要反省，而是要回顾。
因为反省带有找缺点、批判自己的意味；而回顾更加客观，好事坏事都可以想起来。建议大家每周做一次回顾，多去欣赏自己做到的成功的事情，然后再想可以改进的不足之处。
回顾时可以问自己三个问题：
怎么做才能更接近自己的梦想与目标？
还有哪一点可以加以改善？
如果想把这次的经验迁移到下次行动中，该怎么做才好？
把这些写下来，下次你就容易开始了。

看完这个影片，找一件你一直拖着没做的事，去做十秒。
每一次十秒的尝试，都是在重建你和行动之间的信任。不是逼自己变强，而是顺着大脑的规则，轻轻推自己一把。
