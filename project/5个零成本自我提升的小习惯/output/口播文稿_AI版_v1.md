# 5个零成本自我提升的小习惯 · 口播文稿（AI版 v1）

下班回到家筋疲力尽，只想瘫在沙发上滑手机。结果两三个小时过去，身体没有得到放松，心里反而多了一股空虚和焦虑。偶尔想看几页书充实自己，过一个星期再回想，脑袋里又是一片空白。
其实，真正的自我提升不需要花大钱买课，也不用把自己逼得太紧。顺着下班到睡前的这两三个小时，做好下面这5个零成本、不费力的小习惯，就能在放松的同时，把学到的东西留住、把焦虑清空。

第一个小习惯：利用碎片时间阅读，把重点放在消化和输出。

我见过最容易失败的阅读目标，就是规定自己一个月要看多少本书、每天晚上必须坐在书桌前看够一小时。白天上班已经够累了，这种硬邦邦的目标往往坚持不了几天就会放弃。
还有另一种情况。曾经有位朋友跟我抱怨，说他一年看超过五十本书，也在书上画满了重点，可是现在回头想，大部分内容都记不得了。我就问他，那你看完之后做了什么？他说没有，看完就继续看下一本。
这其实就是大多数人的学习模式：读完一本书、上完一堂课、看完一支影片，当下觉得热血沸腾、收获满满，然后立刻就进入下一个内容。之所以这么容易忘，不是因为你不够认真，而是很多人以为学习的关键在于输入，拼命看书、听课、看干货影片，却漏掉了后面两个更重要的步骤：消化和输出。

心理学家艾宾浩斯提出过著名的遗忘曲线，研究发现人类的大脑天生就很容易遗忘。大脑其实一直在问：刚刚进来的这个资讯重要吗？如果你看完之后没有再次使用或回想过它，大脑就会认为它不重要，过几天直接删掉。所以，真正重要的从来不是你读了多少，而是能留下多少。

与其强迫自己下班后坐定捧着一本书苦读，不如改用碎片时间来阅读。比如通勤坐车、等车，或者睡前的一小段时间，一天加起来至少也有四五十分钟。当我们短时间接收大量资讯时，大脑根本来不及消化；反而在坐车时读一点，留出空白去思考，吸收效果要好得多。
认知心理学有一个很重要的理论叫做提取练习，简单来说就是主动把知识从大脑里提取出来。很多人认为学习是把资讯放进大脑，但研究发现，真正能够强化记忆的方法，反而是把资讯从大脑里拿出来。因为每一次回想，都是在强化大脑里的神经连接。把一本书重读五遍，效果往往不如看完一遍之后，试着把内容回想五遍。

具体怎么操作呢？我自己在用的一个简单方法，就是每次利用碎片时间读完一个小章节后，先不要急着往下看，把书合上。趁着下车走向目的地的这段路，或者去洗漱、散步的那几分钟，在脑子里跟自己来一场头脑风暴，问自己三个问题：
第一个问题，刚刚那一章到底在讲什么？
第二个问题，这一章最重要的三个重点是什么？
第三个问题，我赞同刚才读到的观点吗，可以怎么运用在生活上？
如果你在书桌前，也可以拿出一张白纸，试着把答案随手写下来。不需要写得很漂亮，重点是千万不要翻书偷看，因为偷看那不叫回想。真正的学习，是在没有答案的情况下，努力从大脑里搜寻资讯。这时候你会发现，很多自己以为看懂的东西，其实根本写不出来，有些概念理解得并不完整，有些重点甚至完全忘了。这时候你才真正知道自己的盲点在哪里。
要是你不喜欢写文字，也可以试着在纸上画简单的心智图。把今天读到的主题写在中间，相关的概念往外延伸。比如今天看的是时间管理，中心主题就写时间管理，旁边延伸出轻重缓急、专注力、行程规划、习惯建立，再接着往下延伸细节。当你能画得出来，就代表大脑已经开始在整理资讯了，而整理本身就是一种消化。许多人以为学习是在阅读的时候发生，但更多时候，学习是在整理的过程中发生的。

消化之后，还要加上第三步输出，知识才会真正变成自己的能力。
物理学家费曼提出过一个很经典的费曼学习法，核心精神很简单：如果你不能简单地解释一件事情，就表示你还没有真正理解它。曾经有位教授也分享过，如果你想知道自己懂不懂一个概念，就试着把它讲给十二岁的小朋友听。
所以每次看完一本书或学到一个新观点，不妨找朋友分享，或者干脆拿起手机打开录音，假装自己是老师，花两三分钟把内容讲一遍。你会惊讶地发现，哪些地方讲得很顺，哪些地方讲到一半就卡住了。那些卡住的地方，就是下一步需要回头弄懂的地方。
一本书买回来放在书架上不会改变人生，一堂课放在收藏夹里也不会改变人生。学习不是看过、听过、画过重点，真正的学习，是能够回想出来、说得出来、做得出来。

第二个小习惯：睡前预先为隔天留出5%的精力。

下班路上或晚饭后充实了大脑，到了晚上九点、十点，就不要再逼自己去啃难懂的东西了。在去洗漱休息之前，你可以花短短几分钟，帮明天的自己做一点准备，这能让你每天早上都保持从容、精致地出门，再也不会手忙脚乱。
很多人觉得如果自己没办法早起，拥有那个高效的“黄金一小时”，这一天好像就输在了起跑线上。但其实，决定你全天工作状态的，往往不是你有没有五点起床，而是你出门前的那半个小时过得怎么样。
如果你早上醒来就已经觉得很累，还要在出门前处理一大堆琐事：站在衣柜前纠结今天穿哪件衣服、到处翻找钥匙和文件、匆匆忙忙决定早餐吃什么。心理学上发现，人的大脑每天能做的决策是有限的。大清早把精力全耗在这些琐碎的小决定上，还没到公司人就已经心累了一半，上班后的工作自然会变得更沉重、更辛苦。

其实只要在每天睡前，预先为隔天留出5%的精力。花短短三五分钟，先把明天要穿的衣服挑好挂出来，把要背的包收拾妥当，将必需品提前放进包里，这样隔天就绝对不会忘带东西；你甚至可以提前想好明天早上想化什么妆、吃什么早餐。
这样做，等于直接把隔天早上出门前的时间变得非常充裕。你不再需要狼狈地东翻西找，而是可以从容地喝杯咖啡，化一个漂亮的妆，带着这种稳稳的掌控感去开启新的一天。

第三个小习惯：进行数字断舍离，睡前远离电子屏幕。

把明天的东西收拾好、洗完澡出来，就到了准备入睡的时间。这时候最关键的一件事，就是做一次数字断舍离。
睡前滑手机是降低睡眠质量的一大主因。很多人觉得自己平时入睡不算困难，玩一会儿手机也没什么影响。但如果你明明睡够了时间，每天早上起床却还是觉得昏沉、没精神，那就真的需要建立“睡前至少半小时不使用电子产品”的习惯了。
一方面，屏幕的蓝光和密集的资讯会持续刺激我们的大脑；而且睡眠本来是大脑自动整理、巩固白天所学知识的黄金时间。如果你刚在傍晚读了书、做了思考，睡前却又习惯性地拿着手机，毫无目的地打开各种娱乐软件，看了半天都不知道自己到底在看什么，这些杂乱的资讯就会干扰大脑夜间的整理工作。

另一方面，睡觉时一定要把手机设置好睡眠模式。因为手机里有各种各样的App，平时如果开着消息提示，半夜随便弹出一两条通知，就算没有发出声音，只是在床头轻微震动一下，也会在不知不觉中把你从深层睡眠拉回浅层睡眠，导致怎么睡都觉得不够。你可以把手机设置在睡眠期间屏蔽任何通知，只保留家人或朋友的紧急来电。
我们的目标不是完全不用这些科技产品，而是清除社交媒体带来的不必要杂音，让发达的科技来服务我们，而不是控制我们。你也可以在床头放一本纸质书或笔记本，再配一盏柔和的小床头灯，帮自己慢慢戒掉睡前滑手机的习惯。

第四个小习惯：睡前用“大脑倾倒法”，清空思绪杂音。

把手机放远、打开床头灯之后，有些人会遇到另一个困扰：周围安静下来了，脑子里的念头却开始停不下来。
很多时候我们的累，并不是身体上的疲惫，而是大脑里有太多的杂音。比如明天要交的报告、今天某个人说过的一句让你介意的话，又或者是突然不知从哪冒出来的念头。只要这些事情还悬在半空没有着落，大脑怕你忘记，就会一直紧绷着反复提醒你。
这时候，你可以试试“大脑倾倒法”。拿出一本放在床头的笔记本，甚至只是一张白纸，完全不需要管字迹有多潦草，也不需要有任何逻辑，只要把此刻脑海里闪过的所有事情——无论是明天的工作、令你担心的事，还是突发的灵感，全部写下来。

这个过程就像是把大脑里的东西直接转移到纸上，告诉大脑：这些事已经妥善记下来了，现在可以放心休息了。除了能清理杂乱的思绪、缓解睡前焦虑之外，它还能让我们把平时隐藏在心底的一些真实想法，透过文字诚实地告诉自己。
当你花三五分钟把脑子里的杂音都写下来之后，你会发现心里踏实了许多，晚上也会睡得特别香。

第五个小习惯：每晚5至10分钟身体拉伸，释放紧绷与焦虑。

清空了脑子里的杂念，合上笔记本准备躺下之前，最后花短短5到10分钟，帮自己的身体做个简单的拉伸放松。
在这个机不离手的时代，我们每天不是坐着盯着电脑，就是低头看着手机，一天下来，肩颈、后背和盆骨其实都处于非常紧绷的状态。而这种身体上的紧绷，反过来又会影响我们的心情，让人莫名觉得烦躁。
你不需要强迫自己大晚上去做高强度的运动，或者下楼跑步——当然能做到最好，但如果实在累得不想动，只需每晚睡前在床上，或者最好在瑜伽垫上，做5到10分钟简单的伸展运动。

拉伸的时候不需要追求高难度动作，重点是配合缓慢的呼吸，去感受身体平时绷得最紧的地方，让它随着呼气一点一点放松下来。因为当身体放松之后，我们的心灵也会随之放松，焦虑感自然也就散去了。

其实，自我投资从来都不是一场比赛，而是每天下班后，与自己进行的一场温柔对话。
这五个微习惯不需要任何金钱成本，也不要求你从今晚开始就全部做到完美。等一下关掉这支影片，你不妨先挑一个最轻松的试试看：比如合上屏幕回想一下刚刚听到的三个重点，或者在洗漱前花三分钟把明天要穿的衣服挑好。只要你肯踏出第一步，时间就会在不知不觉中给你一个满意的答案。
