## 三、📦 封面与标题设计方案（繁体中文 · 3组）

> **💡 结合包装记忆（`PKG-0001`、`PKG-0002`、`PKG-0003`）的设计策略**：
> 1. 遵循 `PKG-0001` 与 `PKG-0002`：标题采用**“痛点/损失感 → 科学机制/背书 → 低门槛动作 → 明确收益”**结构；封面文字与标题**零重复**，同时提供**经典两行版**与**高转化三行版（身份/痛点 → 收益 → 低成本门槛）**供你按排版习惯选用。

### 方案 1：【痛点对焦 + 科学背书型】（对标 `PKG-0001` / `PKG-0002` 高点击结构，最稳健）

**视频标题**（繁体，51字）：
`下班只會滑手機、看書過一週全忘？哈佛與心理學證實：睡前順手做這5件小事，把知識存進大腦、徹底清空焦慮！`

**封面文字**（繁体，与标题互补零重复）：
* **两行版**：
  `別把下班變加班！`
  `大腦升級只需5件小事`
* **三行版（推荐，7-6-7视觉节奏）**：
  `哈佛×認知心理學`
  `學得快、睡得香`
  `下班只需5件小事`

**画面构图建议（`PKG-0003`）**：
* 暖暗调卧室或客厅沙发场景（床头一盏温暖小台灯+合上的书与小本子，人物舒展放松或从容微笑，区别于苦大仇深的挑灯夜战图），左/右侧大字采用“白+亮黄+亮绿”高对比排版。

**设计说明**：
* **侧重维度**：晚间双重痛点（滑手机累+看书忘）+ 科学实证工具
* **情绪触发**：痛点共鸣 → 低门槛获得感
* **表达风格**：痛点提问 + 权威肯定
* **封面与标题关系**：标题讲具体痛点与结果，封面提炼“别把下班变加班 / 只需5件小事”的低门槛承诺。
* **标题党等级**：✓ 绿灯区（文稿确实包含哈佛医学院睡眠实验与华盛顿大学、贝勒大学心理学实验）。

`別再逼自己下班後「死磕自律」了！養成這5個順應大腦規律的零成本微習慣，邊休息邊記住新知識，隔天滿血復活`

**封面文字**（繁体，强化正反对比）：
* **两行版**：
  `停止下班假努力`
  `零成本變強5習慣`

  `下班總是累又焦慮？`

**设计说明**：
