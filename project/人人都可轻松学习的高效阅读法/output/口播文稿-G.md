# 人人都可轻松学习的高效阅读法

年初列了二十本书的书单，大半年过去，第一本的书签还卡在第二十八页。或者咬牙读完一本，荧光笔画满了，两个月后有人问起，你一个核心观点都讲不出来。

这多半不是毅力的问题，是读法的问题。我们从学校带出来一套应付考试的读法：拿到书从第一页读到最后一页，这本没读完不开下一本，画了重点就当记住了。肯特州立大学的研究团队评估过十种常见学习方法，大家最常用的画线，就被列在低效的一类。

这套读法，正好卡在看书最常出问题的三个地方：翻不开、读不进、记不住。今天就按这三关，讲一套不靠硬啃、带着问题去书里找答案的“猎人式阅读法”：每一关换掉哪个动作，背后有什么研究，今天怎么开始做。

先说翻不开。

书架上没拆塑封的书，很多是同一类：得过大奖、五六百页、腰封上印满名人推荐。买的时候很兴奋，回家一看厚度，就一直没翻。

普林斯顿大学的库尔团队做过六组选择实验：受试者可以在两组任务里自由挑，一组要频繁切换规则，一组很少切换，回报一样。结果人会稳定地避开更费脑子的那组。一本又厚又陌生、不知道什么时候才用得上的书，在大脑看来就是成本高、回报远，手自然会伸向更省力的手机。这是大脑默认的取舍，不是你性格有问题。

选书标准要倒过来：只挑你眼下真正好奇的，或者对手头的事直接有用的。光这两类书，就够你读很多年。消遣的小说和漫画也算，先让翻书这件事变得愉快。

对某个问题有了兴趣，比如最近想调睡眠、刚开始学理财，可以一次找三到五本同主题的书连着读。雷希特和莱斯利让六十四名中学生读一段棒球比赛的文章，结果阅读能力弱但懂棒球的学生，复述和总结反而比阅读能力强但不懂棒球的学生好。很多时候，决定你读不读得懂的不是阅读能力，而是你对这个主题已经知道多少。同主题的第一本读得慢，到第三、第四本，很多概念已经熟了，速度自然会快起来，读完这几本，你在这个领域就算半个内行了。

选定方向，也别急着买。看书花的不只是钱，还有好几个小时。先翻免费试读或电子图书馆，读几页觉得对胃口，再花五分钟查三件事。一看评分人数和好评率，上千人评分、四五星加起来超过八成的，一般不会太差。二看三星评论，这一条最有用。五星常常都差不多，一星又常带情绪，三星最容易看出一本书真正的短板：如果大家是在骂作者语气武断、态度傲慢，不影响内容，可以读；如果是在说论证有漏洞、拿旧例子凑篇幅，就可以放弃了。三查作者，讲科学或专业方法的书，搜一下作者的学术背景或从业经历，看他够不够格讲这个题目。**五分钟的筛选，能帮你省下读一本烂书的好几个小时。**

书选好了，很多人读两天又停了，常见原因是两个念头：“等有整块时间再读”和“这本没读完不能开下一本”。

看书不需要从一而终。一本书读不顺，硬撑下去的结果往往是哪本都不读了。你可以同时开三四本深浅不同的书，比如一本跟工作有关的、一本讲健康的、一本小说，精神好就读难的，累了就翻轻松的。

整块时间也不会自己出现。跟运动一样，不提前排进日程，这件事就不会发生。可以按精力分两段：白天最清醒的时段，读需要动脑的书；睡前二十到三十分钟，翻还没决定要不要精读的书，或者看闲书。顺手记一下读完一本花了几个小时。很多人记下来才发现，每周三到五小时专注时间，加上睡前那点时间，一周六个小时左右，就够读完一本。一年下来，就算打个对折，也有二十多本。

还有一个能让阅读量明显增加的做法：把看书变成无聊时的默认动作。心理学家温蒂·伍德让受试者在一天里随机被提醒、当场记下自己正在做什么，结果发现，我们每天大约百分之四十三的行为，是在熟悉的场景里自动发生的习惯。排队、等车，一觉得无聊，手已经把手机解锁了。靠意志力去压这种自动反应很累，换掉它后面那个动作要省力得多。

下次想找点东西打发时间，把打开社交软件换成打开电子书，或者翻手边的书。漫画、故事集都行，关键是这是你主动选的内容，不是算法推给你的。包里放一台轻便的阅读器，或者在沙发和床头放几本章节短、每章独立的书，翻三分钟就能读完一个完整的观点。**把无聊时掏手机换成翻两页书，被短视频占走的注意力，会一点点回到你手上。**

能翻开书之后，第二关是读不进。很多人从第一章第一页往下读，十几分钟就开始犯困，一段话看了三遍，字都认识，就是没进脑子。

问题出在一翻开就直接读正文。人的工作记忆一次只能处理很少的信息，没有目标地读，每句话看起来都一样重要，大脑很快就装不下了，读到后面，前面的已经忘了。

更好的做法是，读正文前先花十五到二十分钟，把封面、封底、目录和前言看一遍，然后写下三个你最想问作者的问题。

比如一本讲精力管理的书，前言说“很多人累，不是睡得少，而是恢复方式不对”，目录里有一章讲“工位上的微恢复”，还有一章讲“压力与炎症”。你可以这样问：为什么周末补觉反而更累？这对我下午三点犯困有什么用？那两章给了哪些证据，有没有明天就能用的做法？问题越具体越好。“这本书讲了什么”太泛，“为什么周末补觉更累”这种问题，读的时候一碰到相关内容，你自然会停下来。

孩子读课外书也能这样做。翻开前先看目录，让他说说这本书可能在讲什么、他最想知道哪一点，再去书里找。

这在认知心理学里叫“读前提问效应”。理查兰德和科内尔等人做过实验，让受试者在读一篇较难的科普文章前先答题。因为没读过，答对率不到百分之十，绝大多数都答错了；可读完再测，那些提前被问过的题，正确率到了百分之七十五左右，明显高于把这段时间全用来读的对照组。卡彭特和潘在2023年的综述里补充了一点：读前提问对被问到的内容效果最强，对没问到的内容帮助有限。这就是为什么要先看完目录和前言再写问题，把问题问在全书最核心的地方。**没有问题地读，读到哪算哪；带着问题读，你是在书里找答案。**

进入正文后，可以用手指或鼠标光标带着视线往下走，同时练习一次看一整句，而不是一个字一个字地看。眼动研究者基思·雷纳在综述里提到，阅读时大约百分之十到十五的眼跳是往回看的，文字一难、读不懂时会更多。手指带读的作用，是把注意力留在正在读的这一行。这个技巧需要练，一开始很耗精力，可以先拿不太难的书练，先求稳，不用求快。如果要边读边记，把阅读器立起来，或者用书立把纸质书夹平，空出两只手来写。

这样读很耗脑力。大约每二十五分钟，觉得注意力开始散了，就站起来活动一下、喝口水。读满九十分钟，出门走一走，什么都别想。纽约大学达瓦奇团队发表在《神经元》期刊的研究发现，学完之后清醒地安静休息时，海马体和大脑皮层之间的联系会增强，增强得越多，之后记得越好。休息的这十几分钟不是偷懒，大脑还在处理刚读的内容。

最后一关是记不住。

很多人习惯拿荧光笔，或者在电子书上把好句子都标出来，标完就觉得是自己的了。前面提到的邓洛斯基团队把画线和高亮列为低效方法，因为它很少带来深入思考，还容易让人产生“我看过、我很熟”的错觉，有时甚至会把文章切成碎片，影响你理解整体的逻辑。

精读时可以不画线，改成边读边记。用备忘录或本子就够了。看到有启发的地方，用自己的话简单记下来，后面加一个括号，写下你当时的反应：想到了自己的什么经历，哪里没看懂，或者哪里不同意作者。

比如读一本讲亲子沟通的书，记下“夸孩子要夸具体的努力，不要夸聪明”，括号里写：“上次夸他聪明，这周遇到难题他就不肯动笔，可能真有关系。但作者说完全不能夸天赋，是不是太绝对？看下一章怎么说。”

括号里的每一句，都要你把作者的话和自己已有的经验连起来，理解就发生在这一步。这在认知科学里叫“自我解释效应”。米歇尔·季的实验里，读的时候解释得多的学生，全都建立了正确的理解；没被要求解释、只读两遍的学生，很多人没做到。比斯拉团队后来汇总了六十四项研究、近六千名学习者的数据，结论一致：引导学习者自己解释，学习效果会稳定提升。

括号笔记只用在要精读的书上，闲书照常轻松读。刚开始，一章写一两个括号就够了；写多了你会发现，自己开始会跟作者争论了。一本书读完，你手里就是一份跟作者来回讨论的笔记。把它从头看一遍，核对开头那三个问题有没有找到答案，再写几条收获。

读完之后还差一步：输出。**只有消化过、用某种方式讲出来或写出来的书，才算真正读过。**你讲不出来的地方，往往就是你以为懂了、还没真懂的地方。有人说自己一年读一百本，你可以问他有没有写过读书心得，公开不公开都行。如果一篇都没写过，随便挑一本问他讲了什么，大概率答不上来。

输出不用很复杂。合上书写一两百字小结，就按开头那三个问题来写，每个问题答一两句；或者打开语音备忘录，像跟朋友聊天一样讲三分钟这本书帮你解决了什么问题，讲得顺就算过关。熟练之后，可以试着把心得发到社交平台。写给别人看，你会逼自己把话想清楚。哪怕一开始只有几个人点赞、留言，这种真实的反馈也会推着你去读下一本。坚持下来，你得到的不只是一张书单，而是一套能很快把陌生领域学进来的方法。

今晚就可以试一次，只要十五分钟：从书架上拿一本你最近最感兴趣、或者一直没读完的书，先别翻第一章；用十分钟看封面、目录和前言，写下三个想问作者的问题；再翻到最能回答第一个问题的那一节，用手指带着读五分钟，不画线，在旁边写一个括号，记下一句你的想法。

写完后，可以把书名和你的三个问题留在评论区，这就是你的第一次输出。我是遊牧人，我们下期见。
