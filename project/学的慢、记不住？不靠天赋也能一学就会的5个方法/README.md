## 数据分析

- 分析复核日期：2026-11-17
- 现象：视频发布初期（最初9小时）因使用“學得慢 記不住？／一學就會的／5個高效方法”封面及“打破『流暢錯覺』”长标题，单点点击率从首小时8.4%下探至凌晨3.2%（首日整体点击率5.7%）。随后开启三向控制变量A/B测试：将封面换为暗调书房思考图+“看過記不住？／學習力翻倍／只需5個小改變”后，观看时长份额由29.4%升至32.6%；再将标题换为“為什麼看懂了還是記不住？別再重複閱讀了！腦科學證實的5個高效學習法，學什麼都又快又牢｜高效學習#24”后，观看时长份额进一步升至38.0%（较组1相对高出29.3%）。锁定第3组后，截至2026-11-17累计展示17.1万、展示点击率5.2%、观看3.4万、深度观看9千、平均观看时长3:34（34%）、0:30留存58%、新增订阅+99、赞386、分享达827次。
- 证据：[归档用数据信息.md](./归档用数据信息.md)、[实际封面-归档实图.png](./output/实际封面-归档实图.png)及2026-10-24用户提供的后台CTR趋势与三向A/B测试截图。
- 限制/原因：YouTube的A/B测试指标为“观看时长份额”而非单纯点击率，且缺少不同流量来源的独立CTR拆解，不能将后续长尾3.4万观看和827次分享单独归因于某一项文稿或包装改动。
- 结论：同场控制变量测试支持“痛点+强结果+低门槛”三行独立封面优于“一學就會的”修饰语拆行封面，且“腦科學證實+又快又牢”直白标题优于“流暢錯覺”学术名词标题；跨期普适性仍作为候选记忆继续观察。
- 结论状态：待验证
- 可复用经验：
- 待验证假设：三行封面第二行直接给独立强结果、第三行给低门槛成本，配合直白脑科学背书标题，比修饰语拆行和陌生学术概念更能承接推荐流受众；长文稿通过补充进阶标准和跨学科案例而非叠加装饰性比喻，有助于维持完播与高分享率。
- 下一期验证动作：在后续学习方法类视频中继续观察封面三行独立信息结构与直白结果标题的点击率和观看时长表现。
