## 数据分析

- 分析复核日期：2026-11-01
- 现象：视频（时长10:56）发布后最初12小时平均观看时长为3:29（与平时差不多），观看次数高于平时；但随展示从1.2万扩至3.4万（浏览功能占93.0%），累计展示点击率由5.4%降至4.3%（1天3小时节点为3.3%）。期间使用同一书房女生底图和同一标题进行约15小时的三版封面文案A/B测试，三版观看时长份额分别为34.4%、31.2%、34.3%，近乎平局，未能拉升整体点击率。
- 证据：本期数据记录中 2026-10-31 至 2026-11-01 的 YouTube 后台覆盖面、互动、流量来源与 A/B 测试截图。
- 限制/原因：本期与近期多期记忆题材（如#21、#25）发布时间紧邻，且三版测试图共用近期高频重复的“左黑底+右暖光女生看书”底图及同一泛合集标题，缺少独立底图对照，尚不能单独把低点击率归因于单一词句。
- 结论：在首页浏览推荐占93%且近期连发相近题材的背景下，保留相同人物底图、配色版式和同一标题、仅微调封面文案或增减行数，未能形成有效点击差异。
- 结论状态：待验证
- 可复用经验：
- 待验证假设：更换底层视觉构图（跳出常规书房女生看书模板）并改用具象、反直觉钩子，可能比同底图换口号更能打破老观众与首页泛受众的视觉疲劳。
