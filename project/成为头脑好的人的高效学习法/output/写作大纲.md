# 《成为“头脑好的人”的高效学习法》创作大纲（分段施工图）

## 一、承诺回顾
- **一句话承诺**：戒掉 84% 的人都在踩的“假努力”错觉，用全美前 1% 医生的 6 步闭环学习系统，把看过的书真正刻进脑子里。
- **承诺类型**：认知颠覆型 + 案例系统拆解型（复合型）
- **标题方向**：弱化书名，突出“看书踏实合上全忘 / 84%假努力陷阱 / 记性普通的医生考进全美前1% / 6步闭环学习法”。
- **风格约束**：最大限度少用比喻，禁止贯穿全文的比喻，严格去 AI 味。

## 二、叙事结构與观众情绪曲线
- **结构类型**：痛点打假 + 六连实战追问闯关（载体 $\rightarrow$ 提取 $\rightarrow$ 间隔 $\rightarrow$ 应变 $\rightarrow$ 兜底 $\rightarrow$ 续航）+ 情感与行动收束

| 进度 | 观众状态 | 要达成的转变 | 如何达成 |
| :--- | :--- | :--- | :--- |
| **0–15%**（段落1） | 扎心共鸣 + 警惕 | 渴望破局 | 60秒内抛出“合上书全忘”痛点、安川医生反差故事与圣路易斯华盛顿大学数据（83.6%重复读 vs 1.1%首选主动回想），点破3个假努力与流畅性错觉 |
| **15–42%**（段落2–3） | 恍然大悟 + 意外收获 | 跃跃欲试但担心遗忘 | 抛出“先看薄书+参考书一元化”，再拆解白纸法的“测试+出声+假装教人”三合一与“合意困难” |
| **42–80%**（段落4–6） | 认知升级 + 避坑庆幸 | 掌握全套武器但担心坚持不住 | 用超忆症案例、10%～20%动态公式、米其林白轮胎案例、交错学习禁用期、记忆术10%边界，密集交付反常识干货 |
| **80–100%**（段落7） | 警醒 + 被温暖治愈 | 充满掌控感，今晚就去试 | 揭露咖啡因与酒精抹杀夜间海马体巩固的真相，给出“6页微目标+自我关联+焦虑四步法”，最后用机场大巴陌生女士的鼓励与3分钟微行动收尾 |

## 三、分段施工图

1. **段落 1：痛点破局与打假——为什么看书时很踏实，合上书却全忘？（约 15%）**
   - 挂载资料：安川康介背景（庆应医学部、USMLE全美前1%）与《成为“头脑好的人”的高效学习法》；圣路易斯华盛顿大学（2009）177名本科生调查（83.6%反复阅读、54.8%列为首选、仅1.1%将主动回想列为首选）；科罗拉多大学重复阅读实验與流畅性错觉；8000字文章划重点降低推理表现实验；180名高中生抄写笔记实验；个人学习风格配对实验。
2. **段落 2（追问 1）：不让抄笔记，那错题和补充知识记哪？（约 12%）**
   - 挂载资料：第1章认知六层级（记忆是高阶思考与创新的地基）；第4章选书原则（从极简入门书/科普漫画到大部头）；第1章“参考书一元化”原则（汇总至唯一核心教材，调动书页空间位置记忆）。
3. **段落 3（追问 2）：不靠死记硬背，怎么把知识刻进脑子里？（约 15%）**
   - 挂载资料：《科学》期刊（Karpicke & Blunt, 2011）80名大学生四组实验（默写组一周后成绩最高但考前预测最没自信）；比约克“合意困难”；安川康介“白纸学习法”三效应叠加（测试效应+出声产出效应+假装教学效应）。
4. **段落 4（追问 3）：当时记住了，过几天还是会忘怎么办？（约 15%）**
   - 挂载资料：美国超忆症女士案例；50个西班牙语单词间隔实验（集中背60% vs 隔天80% vs 隔月95%）；第2章最佳复习间隔公式（距离考试/使用总时间的10%～20%）；连续再学习与15分钟碎片回想（仅17%大学生掌握）。
5. **段落 5（追问 4）：遇到复杂体系，或者考场题型一变就懵怎么办？（约 18%）**
   - 挂载资料：精致化提问与自我解释（米其林白色轮胎与三星美食指南案例）+ 元认知掌握度评估；交错学习与美国700多名中学生实验（4个月后突击测试 71% vs 40%）；交错学习的新手禁用期（基础薄弱严禁盲目交错）。
6. **段落 6（追问 5）：遇到毫无逻辑的死知识怎么办？（约 5%）**
   - 挂载资料：第3章三大记忆术（视觉转换法、故事法、位置记忆法/记忆宫殿）及作者的科学局限性声明（实用度有限，先搞定90%理解型知识，仅用其兜底10%孤立死知识）。
7. **段落 7（追问 6）：方法都懂，坚持不下去、脑子转不动怎么办？（约 20%）**
   - 挂载资料：睡眠海马体记忆巩固；下午咖啡因与睡前酒精对睡眠结构和夜间记忆巩固的破坏；手机视线隔离与20分钟快走；42页数学练习册分解为每节6页实验（自我效能感）；自我关联效应与自我决定理论（内在目标 vs 外在目标）；克服焦虑四步书写闭环；美国人终身最后悔调查（教育遗憾居首）+ 机场大巴陌生女士“言语劝说”故事。
