### 原始来源

- 来源类型：YouTube 视频片段（中英字幕转载）
- 来源标题：再不好好用它，你的大腦很快就會廢了 ► 腦外科醫生給你的忠告（Wisdom Bread 智慧麵包，2022-04-02）
- 来源链接：https://www.youtube.com/watch?v=iKehp7FtgLI
- 原访谈：Tom Bilyeu 访谈神经外科医生 Dr. Rahul Jandial（原始访谈期数未核实）
- 内容摘要：大脑是高耗能的“思考之肉”，长期不用的部分会被修剪；建议使用非惯用手、走路时不看手机记路线、学习时保持“比舒适区多一步”的难度。
- 原内容问题：切片内容，只有比喻和权威背书，没有实验证据；把运动皮层说成在顶叶（实际在额叶）；导航例子以失智老人迷路为主，受众视角偏中老年；“左手刷牙防失智”证据弱。
