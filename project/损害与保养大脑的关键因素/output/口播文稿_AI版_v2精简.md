# 台大脑科学教授拆解大脑保养与升级 口播文稿（AI版 v2 精简）

以前一堂课45分钟，你可以从头专心到尾；现在书才看10分钟，脑袋就开始放空，手就想去摸手机。

先别急着觉得自己变笨了。台湾大学心理系教授、脑科学家谢伯让说，想知道脑力有没有退步，不用跟别人比，跟过去的自己比就好。专注的时间明显变短，就是大脑在发警讯。

好消息是，大脑会跟着你的用法改变。不用吃补品，也不用上什么脑力课，把每天都在做的三件事改一点，再学会一个处理情绪的方法，专注力就能慢慢找回来。

**第一个改变：先说目的，再解锁手机**

本来只想休息五分钟，回过神来已经滑了两三个小时。谢教授说，像这样一滑三四个小时停不下来，在脑科学家眼里已经算成瘾了。

但这不全是意志力的问题。先问你一题：老板说今年给你12万奖金，你要一年后一次拿，还是每个月领1万？

大部分人会选每个月1万，谁知道一年后公司还在不在。面对不确定的未来，人天生偏好马上到手的小奖励，心理学叫“延迟折扣”。普林斯顿大学2004年的脑成像研究也发现，眼前的小奖励会让大脑的奖赏系统特别活跃；要等很久的大奖励，得靠前额叶撑着。

短影片正好踩中这一点。手指一滑，一只猫、一段搞笑片段，快乐不大，但一秒就到手。大脑天天领这种小奖励，再回头面对要熬三个月、半年才有结果的事，像学一项新技能、准备考试、读完一本书，就会觉得太慢、太难熬，看几页就想放弃。

不过谢教授也强调，手机本身是中立的。加州大学洛杉矶分校的脑成像研究发现，当你带着问题去主动搜寻资料、筛选信息时，负责思考和决策的前额叶反而会被激活；真正伤脑的，是打开屏幕时脑子里什么都没有，推什么就看什么。

所以不用戒手机，只要加一个动作：解锁之前，先在心里说出这次要做什么。查一个名词、回一条消息、设一个闹钟都行，做完就关掉。如果停两秒还说不出来，那就是手痒，把手机扣回桌上。

一开始，一天拦下自己三次就算过关。做顺了，再把最常滑的那几个App移出首页，让手指多一道关卡。每次打开屏幕都有目的，主导权就回到你手上。

**第二个改变：挑要记动作、要看对手的运动**

运动对身体好，大家都知道。但为什么动的是手脚，变灵光的是脑袋？

谢教授从演化讲起。两百五十万年前，人什么时候需要拼命跑？不是在逃命，就是在打猎。这种时候你得记住猛兽从哪边冲出来、哪里有洞可以躲，还要盯着脚下别被石头绊倒。久而久之，大脑学会了一件事：身体一剧烈动起来，注意力和记忆力就要跟着全开。

大规模数据也支持这一点。瑞典分析过一百二十多万名十八岁男性入伍时的资料，心肺体能越好的人，认知测验的成绩也越高。有氧运动会让身体分泌更多帮助神经细胞修复和生长的物质，比如脑源性神经营养因子；重训练出的肌耐力，则能帮你扛住压力。谢教授自己就是两种都做，平常骑脚踏车，有空也去健身房。

如果想给大脑更强的刺激，有两类运动特别值得做。

第一类要记动作，像跳舞、太极拳、武术。2017年德国马格德堡大学做过对比实验：一组受试者学跳舞，舞步和节奏不停换新的；另一组骑固定单车、健走，做单调重复的耐力训练。一段时间后，两组体能都提升了，但核磁共振显示，只有不断记舞步的那组，负责记忆的海马体增长得更明显，平衡感和空间记忆也进步更快。每换一套新动作，大脑就得重新记一次身体运行的轨迹。

第二类要面对对手，像羽毛球、网球、乒乓球，或者拳击、篮球。一个人跑步可以放空，打球不行，你得在几百毫秒内一直判断：对手要往哪里打？我该怎么接、怎么防？这种高密度的策略预判，加上跟人的互动，对大脑的刺激比单调的慢跑多得多。

平常没运动的，先从每天快走二十分钟开始；已经有在跑步、健身的，每周把其中一两次换成打羽毛球、乒乓球；找不到球伴，就跟着影片学一段新舞步，或者打一套太极拳。手脚不太听使唤、得专心盯着动作的时候，就是大脑正在建立新连接的时候。

**第三个改变：固定入睡时间，睡满完整周期**

白天给了大脑刺激，晚上就要靠睡眠把东西整理好、把废物清掉。

谢教授说，日常生活里对大脑伤害最大的，就是长期睡眠不足。高中生七点多就要到校，上班族加班到半夜，很多人早就习惯睡不够。

睡觉的时候，大脑其实在做清洁。脑细胞之间有空隙，里面是脑脊髓液。白天大脑忙着运作，这些空隙很窄；睡着之后空隙变大，脑脊髓液才流得进去，把白天累积的代谢废物冲出来。2013年美国罗切斯特大学在老鼠身上测到，睡着后这些空隙会扩大大约六成。

睡不够，废物就清不掉。动物实验发现，睡眠被剥夺时，脑中的类淀粉蛋白会越积越多，而这种蛋白跟阿兹海默症、也就是失智症关系密切。临床上还有一种病叫“爆炸头症候群”，患者一睡着，脑中就会听到一声巨响或看到一道强光，当场被吓醒。长期这样睡不好的人，注意力和记忆力都会一路往下掉。

那要睡多久？其实没有标准答案，有人六小时就够，有人要八小时以上。谢教授自己早上送完小孩会再补眠半小时，下午有空也会小睡二三十分钟。

比时数更重要的，是周期完不完整。睡眠大约九十分钟一个周期，前半夜深睡多，主要在清废物；后半夜做梦的快速动眼期变长，主要在整理白天学到的东西。闹钟总是在后半夜把你叫醒，等于每天都少掉一段整理记忆的时间。

所以理想的状态，是每晚睡满四到五个完整周期，大约六到七个半小时。你可以先把入睡时间固定下来，比如每晚十一点睡，先试六点半起床，刚好五个周期。起来还是昏沉，就换个时间点再试几天。起得太早，一整天都会恍恍惚惚；想多睡一点，到时间可能自己就醒了。白天不犯困的那个时长，就是最适合你的。

**最后一个方法：用一句话说出你的情绪**

讲到这里，你可能会想：这些道理我都懂，可是被主管骂了一顿、考试压力一来，回到家还是只想瘫着滑手机。

因为底下还卡着一件事：情绪。

从早年战场上脑外伤士兵的临床案例，到诺贝尔医学奖得主、现代神经科学之父卡哈的研究，都证实了：伤到前额叶，人的性格就会大变；伤到记忆区，记忆可能只剩几十分钟。情绪和大脑的物理结构是绑在一起的。反过来，长期的负面情绪和逆境压力也会伤害大脑。谢教授说，碰到讨厌的老板、被同事排挤霸凌，身体会难受，其实是演化出来的保护警讯，提醒你这个环境不对。可是很多人没有在听，只把不舒服强行压下去，隔天照样回去硬撑，焦虑和忧郁越积越深，专注力也跟着垮掉。

要处理情绪，先要知道情绪是怎么来的。大脑里负责应对危机的是杏仁核，但脑科学有一种观点认为，情绪是大脑“解读”出来的。同样是心跳加快、脸发热，在选举造势现场，大脑会解读成兴奋；在草原上面对一头狮子，就会解读成害怕。身体反应一样，处境不同，情绪就不同。

既然情绪是解读出来的，你就有机会介入。方法叫“情绪标记”，分两步。

第一步，先察觉。烦躁、看不下书的时候，先停下来，别顺手拿起手机逃开，告诉自己：我现在压力很大。少了这一步，你只会被情绪带着走。

第二步，用具体的话把它说出来。比如：“我现在心跳很快，静不下来，是因为明天要交报告，我在焦虑。”

光是说出来就有用。加州大学洛杉矶分校的马修·利伯曼做过脑部扫描实验，受试者看到愤怒或害怕的脸孔照片时，杏仁核反应很强；可只要让他们用一个词说出这是什么情绪，前额叶就开始活跃，杏仁核的反应也明显降下来。负责语言和理性的前额叶一上线，你就不会完全被情绪牵着走。

这也说明了为什么十八、十九世纪的人相信，多读小说能让情绪更成熟。读小说，就是在学怎么分辨、描述各种感受。能用的词越多，你就越能把情绪说准。

**结语**

大脑有没有变钝，不用跟别人比，跟以前的自己比就好。

等一下关掉这支影片，下一次拿起手机前，先说出你要做什么。这礼拜找一天去打场球，今晚固定时间关灯，下次心烦的时候，用一句话把情绪说出来。

哪天你发现自己又能专心坐满45分钟，就知道大脑已经回来了。
