# 记忆查询约定

本文件只约定两件事：按哪个阶段查，以及查哪些状态。查询本身没有写入权。

## 1. 阶段

允许的阶段如下：

| 中文名称 | 兼容写法 |
| --- | --- |
| 大纲 | outline、写作大纲、阶段4、outline-drafting |
| 文稿 | script、口播文稿、阶段5 |
| 包装 | packaging、发布物料、阶段6 |

记忆可以写多个阶段，例如“阶段：大纲,文稿”。需要三个阶段都能看到时，写“阶段：大纲,文稿,包装”。

## 2. 状态

只有三种状态：

- 候选：尚未完成长期确认。
- 正式：经过多次验证并由用户确认。
- 暂存：准备抛弃，默认不返回。

省略状态时，查询范围是“候选 + 正式”。这里的“全部记忆”不包含暂存。

明确查询“全部”时，结果与省略状态相同，仍只返回候选和正式。明确查询“暂存”时，只返回暂存记忆，不与其他状态混合。明确查询“候选”或“正式”时，只返回对应状态。

## 3. 命令

```powershell
pwsh.exe -NoProfile -File .agents/skills/memory-query/scripts/query_memory.ps1 -Stage 文稿
pwsh.exe -NoProfile -File .agents/skills/memory-query/scripts/query_memory.ps1 -Stage 文稿 -Status 全部
pwsh.exe -NoProfile -File .agents/skills/memory-query/scripts/query_memory.ps1 -Stage 文稿 -Status 正式
pwsh.exe -NoProfile -File .agents/skills/memory-query/scripts/query_memory.ps1 -Stage 文稿 -Status 候选
pwsh.exe -NoProfile -File .agents/skills/memory-query/scripts/query_memory.ps1 -Stage 文稿 -Status 暂存
```

`-Format json` 只改变输出显示形式。`-RepoRoot` 只用于测试或从其他目录调用，不属于记忆筛选条件。脚本会返回该阶段符合状态条件的全部记忆，不在查询层截断。

## 4. 新记忆格式

最小格式如下：

```text
### M-0001｜标题
阶段：文稿
状态：正式
内容：一条可以直接指导创作的记忆。
```

要求：

- 编号必须唯一，并且在内容修改后保持不变。
- 阶段至少写一个，且只能从大纲、文稿、包装中选择。
- 状态只能是候选、正式或暂存。
- 内容不能为空。

不再要求每条记忆附带项目编号、证据清单、版本链、冲突链、撤销说明或上下文清单。

## 5. 旧记忆兼容

旧文件中的普通标题段落没有编号时，脚本会按“文件名 + 标题 + 顺序”生成旧资料编号，并暂时标为候选。旧资料的阶段根据文件职责作过渡映射：

- 大纲创作技巧记忆：大纲。
- 文稿撰写记忆：文稿。
- 往期影片信息记录：大纲、文稿、包装。旧内容统一暂时标为候选，未来由整理记忆的 Skill 决定是否拆分、保留或暂存。
- 重大决策记忆：大纲、文稿、包装。

未来写入记忆的 Skill 应直接使用新格式。查询脚本不负责迁移、改写或确认旧资料，也不判断某份旧文件是否值得用于创作。

## 6. 失败处理

以下情况直接停止：

- 阶段或状态名称不认识；
- 记忆文件无法读取；
- 新格式记忆缺少编号、阶段、状态或内容；
- 新格式记忆出现重复编号；
- 文件中出现无法判断边界的受控记忆段落。

查询结果为空不是错误。空结果必须明确显示为零条，调用方不得自行猜测规则，也不得退回读取全部原文。

本 Skill 永远不会新增、修改、升级、降级、暂存或删除记忆。
