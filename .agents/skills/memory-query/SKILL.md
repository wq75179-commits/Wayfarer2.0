# 记忆查询

## 目的

本 Skill 是创作流程读取通用频道记忆的唯一入口。它只回答一个问题：

> 在当前阶段，哪些记忆可以给创作流程参考？

记忆不按项目分割。当前项目的事实仍由该项目自己的 README 提供；本 Skill 不读取项目事实，也不使用项目编号筛选长期记忆。

## 记忆状态

记忆只有三种状态：

- **候选**：刚整理出的经验，等待继续观察和确认。
- **正式**：经过多次验证并由用户确认，可以稳定参考。
- **暂存**：准备抛弃的记忆。默认不返回，只有用户明确查询时才显示。

本 Skill 不负责改变状态。候选是否变成正式、正式是否变成暂存，都由其他记忆整理流程和用户决定。

## 查询规则

查询时只需要提供：

1. **阶段**：只能是大纲、文稿或包装。
2. **状态**：可省略。省略时返回该阶段的候选和正式记忆，不返回暂存记忆。

同一条记忆可以适用于多个阶段。需要三个阶段都能看到时，直接写“阶段：大纲,文稿,包装”。

阶段名称可以使用创作手册中的中文名称，也可以使用旧入口的名称；旧入口只作为兼容写法，不会产生另一套记忆。

## 最小记忆格式

新记忆建议使用以下格式：

```text
### M-0001｜开场先解除羞耻感
阶段：文稿
状态：正式
内容：先承认观众并非不努力，再指出方法问题。
```

每条记忆必须有唯一编号。编号建立后不要因为标题或内容修改而改变。

旧记忆如果还没有编号，查询时会根据文件名、标题和顺序生成一个稳定的旧资料编号，并标记为候选。这个编号只用于查询和定位，不代表用户已经确认该记忆为正式规则。

## 调用方式

从仓库根目录使用 PowerShell 启动器：

```powershell
pwsh.exe -NoProfile -File .agents/skills/memory-query/scripts/query_memory.ps1 -Stage 文稿
pwsh.exe -NoProfile -File .agents/skills/memory-query/scripts/query_memory.ps1 -Stage 文稿 -Status 全部
pwsh.exe -NoProfile -File .agents/skills/memory-query/scripts/query_memory.ps1 -Stage 文稿 -Status 候选
pwsh.exe -NoProfile -File .agents/skills/memory-query/scripts/query_memory.ps1 -Stage 文稿 -Status 暂存
```

结果默认使用紧凑的中文清单。需要交给其他程序读取时，可以加上 `-Format json`；这只改变显示方式，不改变查询结果。每条结果只显示编号、标题、阶段、状态和内容。默认会返回该阶段符合状态条件的全部记忆。

## 使用边界

- 只读取 `memories/` 下的记忆文件。
- 记忆是频道共用内容，不按项目编号切割。
- 不把暂存记忆混入默认结果。
- 不根据播放量、调用次数或模型判断改变状态。
- 不提出候选、不提醒升级、不判断失效、不执行删除。
- 不修改记忆文件、项目 README 或任何其他文件。
- 查询为空时，只返回空清单；调用方必须使用本期用户要求和当前创作材料，不得自行猜测长期规则。

## 出错时的处理

如果阶段名称不认识、记忆格式无法读懂、正式记忆缺少基本信息、编号重复或文件无法读取，脚本会停止并说明原因。

它不会把全部原始记忆交给创作 AI 作为退路，也不会因为没有结果而补写“通用最佳实践”。
