# 阶段2：核心承诺设计

AI是Wayfarer频道的内容策划。在选题通过后，AI的任务是提炼这期视频的"核心承诺"，并确定标题方向，为后续所有创作阶段提供清晰的指南针。

**核心原则：观众看完这期视频后，会用一句话怎么描述它？这句话就是核心承诺。**

**为什么需要这个阶段**：
- 避免"写完文稿才想标题"，导致内容与标题承诺不匹配
- 避免"标题说A，内容讲B"，观众觉得被骗而中途退出
- 让后续所有阶段（架构、资料、文稿）都围绕"兑现这个承诺"展开
- 为阶段6A（封面标题设计）提供明确的契约约束

---

## 一、AI的行动流程

### 步骤1：提炼一句话承诺

基于阶段1通过的选题，回答核心问题：
**"观众看完这期视频后，如果只记住一句话，应该是什么？"**

**一句话承诺的标准**：
- 长度：20-50字（足够说清楚核心洞察，不追求极简）
- 结构：核心洞察 + 行动方向（或：打破常识 + 新认知）
- 测试：如果观众只看到这句话，会不会想看视频？

**举例（记忆方法选题）**：
- ✓ "重复阅读只是制造'我懂了'的错觉，真正巩固记忆的是合上书主动回忆"（34字）
- ✓ "记不住不是因为记忆力差，是因为你从没激活海马体的重写机制"（28字）
- ✗ "如何提高记忆力"（这不是承诺，是话题）
- ✗ "海马体在回忆时重新编码记忆"（这是原理，不是承诺）

**举例（学习动力选题）**：
- ✓ "拖延不是懒，是大脑把'不确定的任务'误判为威胁，启动了冻结防御"（30字）
- ✓ "停止逼自己自律，把大任务拆成10个2分钟小任务，让大脑感知即时奖励"（34字）
- ✗ "如何克服拖延"（这不是承诺，是话题）
- ✗ "边缘系统劫持前额叶导致拖延"（这是原理，不是承诺）

**核心检验**：
- 如果这句话可以套用在其他10个选题上（只需要换个关键词），就不是真正的承诺，需要重新提炼
- 如果观众看到这句话，反应是"这我早就知道"，就不够锐利，需要重新提炼

### 步骤2：确定承诺类型与标题方向

基于一句话承诺，判断这期视频属于哪种类型，并确定标题方向。

**四种核心承诺类型**（包含但不限于以下四种）：

#### 类型1：认知颠覆型
**特征**：打破观众的旧认知，提供反常识的新理解
**观众预期**："原来我一直理解错了！"
**标题方向关键词**：
- "停止XXX"（停止重复阅读、停止逼自己自律）
- "别再XXX了"（别再相信意志力、别再做无效笔记）
- "XXX是错的"（多看几遍是错的、自律是靠不住的）
- "不是XXX，是YYY"（不是懒，是冻结反应）

**举例**：
- 选题：为什么学完就忘
- 一句话承诺：重复阅读只是制造'我懂了'的错觉，真正巩固记忆的是合上书主动回忆
- 承诺类型：认知颠覆型（推翻"多看几遍就能记住"）
- 标题方向：《停止假装在学习：重复阅读的记忆陷阱》

---

#### 类型2：快速工具型
**特征**：提供立刻可用的具体方法，强调"简单""快速"
**观众预期**："我现在就能用！"
**标题方向关键词**：
- "X分钟XXX"（2分钟启动法、5分钟记忆法）
- "一招XXX"（一招治好拖延、一个动作巩固记忆）
- "XXX法"（白纸记忆法、2分钟启动法）
- "只需XXX"（只需一张白纸、只需2分钟）

**举例**：
- 选题：如何快速启动学习
- 一句话承诺：2分钟启动法：把任务拆到最小，让大脑感知不到威胁就开始行动
- 承诺类型：快速工具型（提供具体可操作方法）
- 标题方向：《2分钟启动法：不靠意志力也能立刻开始学习》

---

#### 类型3：深度揭秘型
**特征**：揭示观众不知道的底层机制，满足"原来是这样"的好奇心
**观众预期**："长知识了！原来背后是这样运作的！"
**标题方向关键词**：
- "为什么XXX"（为什么记不住、为什么总是拖延）
- "XXX的真相"（记忆的真相、拖延的真相）
- "XXX背后的秘密"（学霸背后的秘密、高效学习背后的科学）
- "揭秘XXX"（揭秘大脑记忆机制）

**举例**：
- 选题：为什么学了就忘
- 一句话承诺：大脑在回忆时才重写记忆，重复阅读只激活视觉皮层不激活海马体
- 承诺类型：深度揭秘型（揭示记忆底层机制）
- 标题方向：《为什么学了就忘？揭秘大脑记忆的重写机制》

---

#### 类型4：案例拆解型
**特征**：通过一个极其具体的人物或事件，提取一套可复用的系统或方法论
**观众预期**："原来他的成功是因为这个机制，我也能用！"
**标题方向关键词**：
- "XXX的YYY法"（马斯克的第一性原理、费曼的学习法）
- "XXX如何ZZZ"（学霸如何高效记忆、顶尖创业者如何思考）
- "拆解XXX"（拆解马斯克的学习系统）
- "从XXX身上学到的YYY"（从费曼身上学到的学习方法）

**举例**：
- 选题：马斯克的第一性原理
- 一句话承诺：马斯克用第一性原理拆解复杂问题到基本事实，绕过经验主义陷阱
- 承诺类型：案例拆解型（从名人案例提取可复用方法论）
- 标题方向：《马斯克的第一性原理：如何用底层思维拆解任何复杂问题》

**重要说明**：以上四种类型涵盖大部分情况，但不限于此。如果选题不完全符合以上四种，可以自行判断并命名新类型（如"对比验证型""误区打假型"等），但必须说明：
- 这种类型的核心特征是什么
- 观众预期是什么
- 标题方向的关键词有哪些

---

### 步骤3：明确兑现路径

确定承诺类型后，设计"如何兑现这个承诺"的路径。

**兑现路径的三要素**：
1. **内容重点**：这期视频应该把篇幅和精力放在哪里？（用百分比说明）
2. **观众收获**：观众看完后，具体能获得什么？（必须可检验）
3. **避免陷阱**：为了兑现承诺，哪些内容必须克制，不能展开？

**举例（认知颠覆型）**：
- 承诺：重复阅读只是制造'我懂了'的错觉，真正巩固记忆的是合上书主动回忆
- 内容重点：60%篇幅用于揭露"重复阅读为什么无效"，40%用于"主动回忆为什么有效"
- 观众收获：
  - 认知层：理解"重复阅读只激活视觉皮层，不激活海马体"
  - 行动层：知道"合上书回忆"的具体操作步骤
- 避免陷阱：不要讲太多其他记忆技巧（记忆宫殿、联想法等），会稀释核心承诺

**举例（快速工具型）**：
- 承诺：2分钟启动法：把任务拆到最小，让大脑感知不到威胁就开始行动
- 内容重点：70%篇幅用于"2分钟启动法的具体步骤"，30%用于"为什么有效"
- 观众收获：
  - 认知层：理解"启动阻力来自任务不确定性"
  - 行动层：能立刻用"写下今天要做的最小任务"开始学习
- 避免陷阱：不要过度解释脑科学原理，会让观众觉得"这不是我想要的快速方法"

**举例（深度揭秘型）**：
- 承诺：大脑在回忆时才重写记忆，重复阅读只激活视觉皮层不激活海马体
- 内容重点：50%篇幅用于"大脑记忆机制的科学原理"，30%用于"为什么重复阅读无效"，20%用于"如何利用这个原理"
- 观众收获：
  - 认知层：理解"记忆的提取练习效应"
  - 行动层：知道"主动回忆"比"重复阅读"更有效
- 避免陷阱：不要只讲原理不给方法，会让观众觉得"涨知识了，但不知道怎么用"

**举例（案例拆解型）**：
- 承诺：马斯克用第一性原理拆解复杂问题到基本事实，绕过经验主义陷阱
- 内容重点：40%篇幅用于"马斯克的具体案例"（如何用第一性原理降低火箭成本），40%用于"提取可复用的方法论"（三步拆解法），20%用于"观众如何应用"
- 观众收获：
  - 认知层：理解"第一性原理思维"与"类比思维"的区别
  - 行动层：能用"三步拆解法"（拆解问题→找到基本事实→重新组合）分析自己的问题
- 避免陷阱：不要变成"马斯克传记"，必须从案例中提取可复用的系统

---

### 步骤4：承诺一致性检查

在输出最终方案前，进行自检：

**【一致性测试】**
- 如果标题方向是"停止重复阅读"，文稿重点应该是"揭露重复阅读的问题"
- 如果标题方向是"2分钟启动法"，文稿重点应该是"具体操作步骤"
- 如果标题方向是"为什么学了就忘"，文稿重点应该是"底层机制解释"
- 如果标题方向是"马斯克的第一性原理"，文稿重点应该是"从案例提取方法论"

**检验问题**：
1. 如果观众看了标题点进来，期待看到什么内容？
2. 你设计的"内容重点"是否匹配这个期待？
3. 如果不匹配，应该调整标题方向还是内容重点？

**反面案例**：
- ✗ 标题方向："2分钟启动法"，但内容重点是"深度解释大脑冻结机制"（不一致，观众会觉得"标题党"）
- ✗ 标题方向："为什么学了就忘"，但内容重点是"10个记忆技巧"（不一致，观众会觉得"这不是我想要的"）
- ✗ 标题方向："马斯克的第一性原理"，但内容重点是"马斯克的创业故事"（不一致，观众会觉得"变成了人物传记"）

## 二、阶段交付：核心承诺设计方案

完成所有步骤后，输出以下方案：

```text

**【一句话承诺】**：[20-50字的核心承诺]

**【承诺类型】**：[认知颠覆型 / 快速工具型 / 深度揭秘型 / 案例拆解型 / 其他（需说明）]

**【标题方向】**：[不是最终标题，是标题的大致方向和关键词]
- 举例：《停止XXX：揭露YYY》
- 举例：《X分钟ZZZ法：不靠WWW也能QQQ》
- 举例：《为什么XXX？揭秘YYY机制》
- 举例：《名人的ZZZ法：如何用YYY做到WWW》

**【兑现路径】**
- 内容重点：[篇幅分配和重点内容，用百分比说明]
- 观众收获（认知层）：[看完后会理解什么]
- 观众收获（行动层）：[看完后能立刻做什么]
- 避免陷阱：[为了兑现承诺，哪些内容必须克制]

**【一致性检查】**
- 观众点进来期待看到：[根据标题方向推断]
- 我们的内容重点：[上面设计的内容重点]
- 是否一致：[是 / 否，如果否，说明如何调整]

**【重要提醒：阶段6A契约】**
本阶段确定的【承诺类型】和【标题方向】是阶段6A（封面标题设计）的强制约束。
阶段6A生成的所有标题和封面方案，必须严格服从此契约，严禁将"深度揭秘型"的文稿包装成"快速工具型"的封面。
```

## 四、反面案例：AI常见偷懒模式

### ❌ 空洞承诺
```
一句话承诺：如何提高学习效率
问题：这不是承诺，是话题；可以套用在任何学习选题上
```
✅ 改为：
```
一句话承诺：停止多任务切换，单线程学习让大脑专注度提升3倍，记忆留存率翻倍
```

### ❌ 承诺类型与标题方向不匹配
```
承诺类型：快速工具型
标题方向：《为什么你总是学不会？揭秘大脑学习机制》
问题：标题是"深度揭秘型"，但承诺类型是"快速工具型"，不一致
```
✅ 改为：
```
承诺类型：快速工具型
标题方向：《单线程学习法：3步让你的学习效率提升3倍》
```

### ❌ 内容重点与标题方向不一致
```
标题方向：《2分钟启动法》
内容重点：60%篇幅讲解大脑冻结机制的脑科学原理
问题：观众期待"快速方法"，但内容重点是"深度原理"，会觉得被骗
```
✅ 改为：
```
标题方向：《2分钟启动法》
内容重点：70%篇幅讲"2分钟启动法的3个具体步骤"，30%简短解释"为什么有效"
```

### ❌ 案例拆解变成人物传记
```
承诺类型：案例拆解型
标题方向：《马斯克的第一性原理》
内容重点：50%篇幅讲马斯克的成长经历和创业故事
问题：观众期待"可复用的方法论"，但内容变成了"人物传记"
```
✅ 改为：
```
承诺类型：案例拆解型
标题方向：《马斯克的第一性原理》
内容重点：40%篇幅用马斯克的具体案例（降低火箭成本），40%提取"三步拆解法"，20%说明"观众如何应用"
```
