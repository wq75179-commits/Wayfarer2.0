# 单期 README 数据契约

本契约规定 `project/<episode>/README.md` 如何作为单期事实源。同步技能只读取符合本契约的 README，不创建、猜测或修复其中的事实。

## 适用范围

- 同步入口固定为 `project/<目录名>/README.md`。
- `project/example/README.md` 仅是初始化模板，必须排除。
- 项目目录名用于生成回链，不是主键；稳定主键只能是 `episode_id`。
- 同一 `episode_id` 只能存在于一个正式项目 README 中。

## 推荐章节顺序

```markdown
# 本期影片记录

## 基础信息

## 创作确认

## 发布结果

### 数据记录

## 数据分析

## Changelog

## 文档索引
```

章节可以包含额外资料，但不得出现第二个同义的权威字段区。特别是基础信息中不得保留 `分析结果`；所有分析结论只在 `数据分析` 中维护。

## 基础信息

| 字段 | 规则 | 同步用途 |
| --- | --- | --- |
| `episode_id` | 必填；格式 `WF-YYYYMMDD-NN`，例如 `WF-20260801-01` | 长期记忆主键 |
| `创建日期` | 必填；格式 `YYYY-MM-DD` | 单期追溯，不默认投影 |
| `选题` | 必填；一句话包含主题与切入方向 | 一句话选题 |
| `切入角度` | 必填；说明区别于同题材的具体切口 | 内容定位 |
| `受众圈层` | 必填；`第一圈`、`第二圈` 或 `第三圈` | 配额统计 |
| `内容类型` | 必填；`原创` 或 `再创作` | 内容定位 |
| `核心承诺` | 必填；观众看完可以执行的最小改变 | 内容定位 |
| `当前状态` | 归档同步时必须为 `归档` | 是否可同步 |

`episode_id` 一经建立不得因标题、发布日期、目录名或分析结论变更而改变。旧日期时间格式不是合法新 ID；发现后应报告迁移需求并等待用户处理。

## 创作确认

必须使用以下表格，并保留每个阶段的最终确认或不适用状态：

```markdown
| 节点 | 状态 | 确认日期 | 决策摘要 |
| --- | --- | --- | --- |
| 选题 | 已确认 / 未进行 / 不适用 | YYYY-MM-DD 或 — | 一句话最终决策 |
| 简要架构 | 已确认 / 未进行 / 不适用 | YYYY-MM-DD 或 — | 一句话最终决策 |
| 资料补全 | 已确认 / 未进行 / 不适用 | YYYY-MM-DD 或 — | 一句话最终决策 |
| 写作大纲 | 已确认 / 未进行 / 不适用 | YYYY-MM-DD 或 — | 一句话最终决策 |
| 口播文稿 | 已确认 / 未进行 / 不适用 | YYYY-MM-DD 或 — | 一句话最终决策 |
| 发布物料 | 已确认 / 未进行 / 不适用 | YYYY-MM-DD 或 — | 一句话最终决策 |
| 归档 | 已确认 | YYYY-MM-DD | 归档结果与一次性重大决策 |
```

`归档` 行必须为 `已确认`。取消或暂停的影片也必须保留已完成节点与未进行节点，避免把缺失误读为已确认。

## 发布结果

固定字段如下：

| 字段 | 已发布 | 未发布 / 取消 / 暂停 |
| --- | --- | --- |
| `归档结果` | `已发布` | `未发布`、`取消` 或 `暂停` |
| `最终标题` | 必填 | 可为空；如有最终标题可保留 |
| `发布平台` | 必填 | `—` |
| `视频链接` | 必填且为公开视频链接 | `—` |
| `发布时间` | 必填，`YYYY-MM-DD HH:mm` | `—` |
| `视频时长` | 必填，`HH:MM:SS` 或 `MM:SS` | `—` |
| `表现等级` | 基于数据分析填写 | `未评估` |
| `终局原因` | 可选 | 必填 |
| `下一次复核动作` | 可选 | 必填 |

`最终标题`、`发布时间`、`发布平台`、`视频链接` 和 `视频时长` 是发布事实的唯一权威值。不要在基础信息或其他章节复制它们作为另一份真值。

### 数据记录

原始平台数据必须保留在 README。每条记录至少包含：

- 采集日期。
- 统计周期，例如 `发布后 1H`、`发布后 24H`、`发布后 7D`。
- 证据来源，例如平台创作中心截图、平台导出或公开页面。
- 平台、指标名称和数值。

推荐格式：

```markdown
| 采集日期 | 统计周期 | 来源 | 平台 | 指标 | 数值 |
| --- | --- | --- | --- | --- | --- |
| 2026-08-08 | 发布后 7D | B站创作中心截图 | B站 | 播放量 | 12,345 |
```

没有真实数据时明确写 `暂无可核验数据`，不要填写模拟数值。

## 数据分析

这是唯一允许记录分析结论的区域。每次归档或新增数据后，可按以下固定字段更新：

```markdown
- 分析复核日期：YYYY-MM-DD
- 现象：可观察到的变化或结果
- 证据：引用数据记录中的周期、来源和关键指标
- 限制/原因：证据不足、可能混杂因素或已确认原因
- 结论：本期可沉淀的一句话判断
- 结论状态：已验证 / 待验证 / 失败 / 无法判断
- 可复用经验：仅在已验证或失败时填写
- 待验证假设：仅在待验证时填写
- 下一期验证动作：一个可执行的最小动作
```

所有结论都必须同时有 `证据`、`结论状态` 和 `下一期验证动作`。`可复用经验` 不能来自待验证或无法判断的结论。

## Changelog

Changelog 固定放在“数据分析”之后、“文档索引”之前，表头为：

```markdown
| 日期 | 阶段 | 类型 | 决策或变更 | 原因 | 依据 |
| --- | --- | --- | --- | --- | --- |
```

- 只记录用户已确认且会影响本期结果或以后创作的内容。
- 本技能成功更新 `memories/往期影片信息记录.md` 后，可以追加一条 `阶段=记忆整理`、`类型=记忆写入` 的记录。
- 没有写入、用户拒绝或校验失败时不得添加记录。
- 本技能不得修改 Changelog 中已有的决策、原因和依据。
- 完整格式与允许值见 `archive-episode/references/readme-changelog-contract.md`。

## 文档索引

README 只需索引本期目录内的输入、输出与补充文档。长期记忆只能链接到 README 本身，不能直接链接到素材、截图或逐字稿。
