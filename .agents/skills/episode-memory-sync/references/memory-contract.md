# 长期记忆数据契约

`memories/往期影片信息记录.md` 是跨期决策索引，不是单期项目的第二份档案。所有条目都是从 README 派生出的摘要，并保留单期入口回链。

## 文件职责

长期记忆回答以下问题：

- 过去哪些选题、切入方式和行动设计已经被验证？
- 最近十期已发布影片的圈层配额是否符合 7:2:1？
- 哪些假设失败，下一期应避免什么？
- 哪些假设尚未验证，下一期应该如何最小化验证？

以下内容不得复制到长期记忆：逐字稿、完整架构、完整 changelog、原始截图、所有时间点的指标明细、未经证据支持的感受，以及未确认阶段的草稿。

## 文件顶层结构

文件必须包含：

1. `schema_version`，当前为 `1`。
2. `同步口径`，说明权威来源和指标摘要规则。
3. `圈层配额（最近 10 期已发布）`，只统计已发布条目。
4. `影片索引`，每个 `episode_id` 一条。
5. `已验证经验索引`，只引用状态为 `已验证` 或 `失败` 的单期结论。
6. `待验证队列`，只引用状态为 `待验证` 的单期结论。

首次初始化只创建结构，不生成任何影片条目、指标或经验。

## 单期条目格式

每个条目使用 `### <episode_id>` 作为三级标题，字段顺序固定：

```markdown
### WF-YYYYMMDD-NN

- README：[项目 README](../project/<目录名>/README.md)
- 最终标题：
- 发布日期：YYYY-MM-DD HH:mm / 未发布
- 归档日期：YYYY-MM-DD
- 归档结果：已发布 / 未发布 / 取消 / 暂停
- 一句话选题：
- 切入角度：
- 受众圈层：第一圈 / 第二圈 / 第三圈
- 内容类型：原创 / 再创作
- 核心承诺：
- 关键确认：归档已确认；其他对结果有影响的确认节点摘要
- 重大决策摘要：
- 发布摘要：平台=<平台>；链接=<视频链接>；时长=<时长>；表现等级=<等级>
- 指标摘要：统计周期=<周期>；来源=<来源>；<指标>=<数值>
- 结论状态：已验证 / 待验证 / 失败 / 无法判断
- 已验证做法：
- 失败或限制：
- 待验证假设：
- 下一期验证动作：
```

对 `未发布`、`取消` 或 `暂停` 条目，`最终标题` 可为空，`发布摘要` 写为 `未发布`，`指标摘要` 写为 `无（未发布）`。不得伪造平台、链接、时长、表现等级或数据。

## 字段投影与权威性

| 长期记忆字段 | README 来源 | 规则 |
| --- | --- | --- |
| `episode_id` | 基础信息 | 必须完全一致，作为主键 |
| `最终标题` | 发布结果 | README 为空时不得编造 |
| `发布日期` | 发布时间 | 已发布时必须完全一致 |
| `归档日期` | 创作确认的归档行 | 从确认日期提取 |
| `归档结果` | 发布结果 | 必须完全一致 |
| 内容定位字段 | 基础信息 | 压缩为单期摘要，不扩写 |
| `关键确认` | 创作确认 | 只保留影响结果的最终节点 |
| `重大决策摘要` | 创作确认 / 数据分析 / Changelog | 最多一到两句，只摘要本期已确认内容 |
| `发布摘要` | 发布结果 | 已发布时必须含平台、链接、时长和表现等级 |
| `指标摘要` | 数据记录 | 最多一个快照，必须有周期和来源 |
| 结论与行动 | 数据分析 | 不改变结论状态，不新增因果解释 |

如 README 与长期记忆不同，以 README 为准；同步前展示差异，用户确认后才修正长期记忆。

## 配额统计口径

- 范围：按实际 `发布时间` 倒序的最近十个 `归档结果=已发布` 条目。
- 不纳入：未发布、取消、暂停、缺少发布时间或被阻断的条目。
- 显示：每圈数量、样本数、是否符合“第一圈至少 7、第二圈最多 2、第三圈最多 1”。
- 样本不足十期时，显示当前样本数和趋势，不把比例伪装成已完成配额。

## 经验索引与待验证队列

经验索引和待验证队列都是派生索引，不能成为独立事实源。每条均使用以下格式：

```markdown
- 摘要文字（来源：WF-YYYYMMDD-NN）
```

- 已验证经验索引收录 `已验证` 的可复用做法和 `失败` 的失败或限制；同类经验合并时保留多个来源。
- 待验证队列收录 `待验证` 假设及其下一期验证动作。
- `无法判断` 只保留在单期条目，不进入上述两个索引。
- 删除、合并或改写索引时只改变派生摘要，绝不删除对应单期条目。

## 排序与更新

- 已发布条目按发布时间倒序；未发布、取消和暂停条目随后按归档日期倒序。
- 同一 `episode_id` 的新数据、表现等级或结论变更更新原条目，不创建新条目。
- `README` 不存在的孤儿条目只报告，不自动删除。
- 每次成功同步更新文件顶部的 `最近一次同步`，格式为 `YYYY-MM-DD`；该字段描述索引写入时间，不替代任何发布或采集日期。
